# KueTV

Kevin's IPTV player for Android TV and Fire TV. It provides no channels or content; you bring your own
legally accessible sources.

Download the latest TV app: https://github.com/kevinquinnart-bit/OwnTV/releases/latest/download/OwnTV.apk
